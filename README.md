# Banco de Questões de Parasitologia — N4 (600 Questões)
Plataforma interativa estilo **Estratégia MED / Estratégia Concursos**, com 600 questões inéditas baseadas estritamente no conteúdo programático de Parasitoses Intestinais da FIMCA.

## Como Subir na Vercel (Em 1 Minuto)

### Opção 1: Pela Interface Web da Vercel (Arrastar e Soltar)
1. Crie uma conta gratuita em [vercel.com](https://vercel.com).
2. Clique em **Add New...** -> **Project**.
3. Se tiver o repositório no GitHub, conecte este repositório e clique em **Deploy**.
4. Alternativamente, você pode importar a pasta com o arquivo `index.html`.

### Opção 2: Pelo Terminal (Vercel CLI)
Basta rodar na pasta do projeto:
```bash
npx vercel --prod
```

## Recursos da Plataforma
- **600 Questões Inéditas (4 Alternativas A-D)** sem datas ou nomes de autores;
- **Sem Viés de IA**: Proibição de muletas de eliminação fácil (*apenas/somente/exclusivamente/invariavelmente*) e paridade de tamanho das alternativas;
- **Correção Instantânea no Clique**: Clique em qualquer alternativa e veja na hora o resultado (verde para acerto, vermelho para erro);
- **Gabarito Comentado Completo (A, B, C e D)** liberado somente após responder;
- **Construtor de Simulado**: Selecione exatamente quais parasitas e subtópicos deseja treinar;
- **Relatório de Desempenho e Analytics**: Visualização de acertos e erros em número e porcentagem discriminados por cada parasitose e subtópico;
- **Perfis Isolados de Estudantes**: Cada amigo tem seu próprio progresso salvo no navegador sem misturar com os demais.
